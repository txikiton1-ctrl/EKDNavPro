# EKDNavPro APK 1.0

Versión de pruebas de la aplicación Android. No es una versión final.

## Descargar e instalar

[Descargar EKDNavPro 1.0 (APK)](https://github.com/txikiton1-ctrl/EKDNavPro/raw/refs/heads/main/EKDNavPro-1.0.apk)

Android puede pedir permiso para instalar aplicaciones desde el navegador o el gestor de archivos. Revisa los permisos y concede ubicación precisa y notificaciones al iniciar la navegación.

## Funciones incluidas

- Buscar países o regiones y solicitar la descarga de segmentos de datos de BRouter.
- Elegir un destino tocando un punto del mapa; se muestran sus coordenadas y, si está disponible, su dirección.
- Calcular rutas y navegar con GPS.

Los segmentos descargados aparecen en la carpeta Descargas de Android. El cálculo de rutas requiere conexión a internet; descargar segmentos BRouter no habilita por sí solo el cálculo sin conexión.
